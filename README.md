# 刘建峰 · 个人作品集

个人作品集网站，展示项目经历、个人介绍与联系方式。使用原生 HTML / CSS / JavaScript 开发，不依赖任何前端框架与第三方 UI 库。

## 功能

- **项目作品展示**：项目数据由 `js/projects.js` 统一管理，新增项目只需在数组末尾添加对象即可；支持整宽大图与图文分栏两种版式，自动生成封面图。
- **深浅主题切换**：右上角悬浮按钮一键切换浅色 / 深色主题，选择结果通过 `localStorage` 记忆，刷新后保持。
- **导航高亮**：滚动页面时左侧导航自动高亮当前所在区块。
- **入场动画**：内容上移淡入，并尊重系统「减少动态效果」偏好（`prefers-reduced-motion`）。
- **响应式布局**：桌面端为左侧固定边栏 + 右侧内容区，≤860px 自动切换为上下布局，兼容移动端。

## 技术栈

- HTML5
- CSS3（CSS 变量实现主题切换）
- JavaScript（原生，IntersectionObserver、localStorage）

## 运行方式

项目为纯静态站点，无构建步骤：

1. 直接双击打开 `index.html`，或
2. 在项目根目录启动本地服务器：

```bash
python -m http.server 8090
```

然后访问 `http://localhost:8090`。

## 目录结构

```
├── index.html          # 页面结构
├── css/
│   ├── style.css       # 主样式与主题变量
│   └── responsive.css  # 移动端适配
├── js/
│   ├── projects.js     # 项目数据
│   └── main.js         # 渲染与交互逻辑
└── assets/images/      # 项目封面图
```
